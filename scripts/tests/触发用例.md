# 触发用例：老板说的话 → 应该用哪个 Skill

人工跑：在一个临时 HOME（或测试账号）里装好 boss-kb、boss-workbench 两个 Skill，新开对话，一句一句说，看实际用了哪个 Skill。

每次跑完填后三列；和“应该用”对不上的，把实际说法和用到的 Skill 记下来，回头改 description。

| 老板说的话 | 在哪开的对话 | 应该用 | 实际用了哪个 | 日期 | 谁测的 |

说明：
- “知识库加个达人库”是知识库长一个资料模块（boss-kb）；“工作台加个小红书模块”是工作台加功能（boss-workbench）。
- “本周复盘”是整个知识库的每周复盘（boss-kb）；小红书笔记的数据复盘在工作台的小红书内容中心里做。
- 示例里的名字（云杉物流）是虚构的客户，换成你测试库里有的客户名。
